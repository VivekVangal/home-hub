- [ ] **Terra integration — code complete, blocked on manual setup.** Replaces the Garmin-direct idea and supplements Strava: Terra (tryterra.co) is a unified wearable-data API covering Garmin, Fitbit, Apple Health, Oura, Whoop, Polar, Strava, and 500+ providers behind one integration, chosen specifically because (a) Garmin's own developer program requires legal-entity business approval and 2026 new sign-ups are reportedly paused, and (b) Strava's direct API caps free access at 10 athletes with a June 2026 subscription requirement now in effect — neither works for "friends on different platforms." Built the same way as Strava: `functions/terra.js` (pure helpers + tests), three Cloud Functions in `functions/index.js` (`terraGenerateWidgetSession`, `terraSync`, `terraWebhook`), and a Connect/Sync block on the Training page. Unlike Strava's OAuth-code redirect, Terra's connect flow is a hosted "widget session" — Terra handles the provider picker and auth, results land asynchronously via webhook (`terraWebhook`, signature-verified) rather than a URL code param. To go live, still needed: (1) sign up at tryterra.co and get a `dev-id` + API key from the dashboard, (2) `firebase functions:secrets:set TERRA_API_KEY`, `TERRA_DEV_ID`, and `TERRA_SIGNING_SECRET --project home-hub-family-dev` (signing secret comes from Terra's Destinations/Webhooks page), (3) deploy the functions and configure a Webhook destination in the Terra dashboard pointing at the deployed `terraWebhook` HTTPS URL, (4) upgrade `home-hub-family-dev` to the Blaze plan if not already done for Strava.
